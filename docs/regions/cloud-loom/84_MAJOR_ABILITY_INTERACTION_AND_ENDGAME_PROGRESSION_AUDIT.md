# Major Ability Interaction Audit and Endgame Progression

**Purpose:** Verify that the full major toolkit composes coherently before Broken Transit Crown and Periapsis.

# Final major toolkit before endgame

- Attract
- Repel
- Link / Echo
- Latch
- Orbit
- Vector Shift
- Flux
- Phase
- Invert

Overdrive remains optional mastery, not core progression.

# Conceptual roles

## Attract / Repel

Apply directional force.

## Link / Echo

Create multi-actor relationship or solo recorded proxy.

## Latch / Orbit

Commit to / move around anchors.

## Vector Shift

Change airborne route.

## Flux

Change target Resonance eligibility.

## Phase

Change player state occupancy.

## Invert

Reverse a relationship.

These roles are distinct enough to combine.

# Interaction matrix

- Flux + Latch: Flux inert anchor → Latch.
- Flux + Orbit: Flux temporary anchor → Orbit.
- Flux + Phase: Flux node → Phase to alternate-state function.
- Flux + Invert: Flux inert mechanism → Invert its relationship.
- Phase + Latch: Phase → Resonant anchor → Latch.
- Phase + Orbit: Resonant-only orbit path.
- Phase + Invert: enter state where relationship exists → Invert.
- Vector Shift + Flux: midair Flux target → catch route.
- Vector Shift + Phase: shift path → Phase through barrier / catch Phase anchor.
- Vector Shift + Invert: shift into Inverted current route.
- Link + Phase: baseline state compatibility; later Phase Link can bridge briefly.
- Link + Invert: Invert environmental tether while maintaining player Link.
- Echo + Flux/Phase/Invert: recorded semantic actions with stable IDs; no dynamic retargeting.

# Conflict rules

- Invert does not swap Attract/Repel inputs globally.
- Phase does not bypass arbitrary collision.
- Flux does not make all metal interactive.
- Link cannot override friendly-force consent.
- Echo cannot improvise.

# Heat/economy audit

Heat currently supports high-output Resonance, Flux and some Invert.

Phase uses separate charge/recovery by current recommendation.

Reason:

putting every late ability on Heat risks passive waiting.

Prototype must verify total action economy.

# Input-budget audit

Controller complexity must remain manageable.

Potential action surfaces:

- Attack;
- Evade;
- Jump;
- Resonance aim/action;
- Attract/Repel;
- Link;
- Echo controls solo;
- Vector Shift;
- Flux;
- Phase;
- Invert.

Production must explore contextual/chorded mappings without accidental activations.

This is a required usability spike before late-game implementation.

# Backtracking with Invert

## Transit Spine

Reverse rail tug field to reconnect alternate service path.

## Gravity Orchard

Reverse tagged gravity/irrigation relationship on machinery, not global room gravity.

## Solar Foundry

Reverse shutter/mirror drive or thermal transfer mechanism.

## Flooded Observatory

Reverse authored pressure transfer between reservoirs.

## Rust Sea

Reverse field-front control to expose alternate buried route.

## Choir Array

Reverse signal carrier relation on tagged gate.

At least 6–10 Invert returns should exist.

# Broken Transit Crown role

Broken Transit Crown is the first region that assumes fluent composition of nearly all major verbs.

It should not teach a new foundational ability.

Focus:

- recombination;
- transformed old spaces;
- Custodian opposition;
- four-player mastery;
- political/narrative convergence.

# Periapsis role

Periapsis Core is the final configuration space.

It should use:

- prior Anchor outcomes;
- all major movement/state verbs;
- faction/Tessel/Custodian state;
- transformed region support.

The final encounter objective should change by ending path.

# Late-game difficulty

Difficulty should come from:

- composing known verbs;
- reading transformed spaces;
- simultaneous responsibilities;
- tactical build use.

Avoid:

- new foundational verbs after Invert;
- extreme HP inflation;
- long runbacks;
- unreadable VFX density.

# Player-count late-game rule

## Solo

Echo provides required simultaneous actor.

## 2P

Direct paired responsibilities.

## 3P

Pair + flex role.

## 4P

Two active pairs / multiple subsystems.

Do not design endgame only for 4P and patch solo later.

# Session-license audit

Host late-game world may require Flux, Phase and Invert.

Guest lacking permanent unlock receives session license.

Personal progression rewards remain separate.

# Sequence-break policy

With full toolkit, allow optional route skips, collectibles, shortcuts, mastery paths and alternate approaches to optional bosses.

Protect irreversible story triggers, world-state decision ordering, final ending prerequisites and save-critical transitions.

# Cloud Loom outcome → late game

## Maximum Harvest

Crown:

- more powered machinery;
- stronger currents;
- more active threats;
- greater conventional support.

Periapsis:

- higher energy/resource reserve.

## Stable Envelope

Crown:

- calmer exterior;
- fewer powered systems;
- more safe worker routes.

Periapsis:

- lower reserve but better structural stability.

## Distributed Lift

Crown:

- multiple medium-strength routes;
- more cross-region support links.

Periapsis:

- distributed support state and more complex configuration options.

# Choir + Loom interaction

Examples:

- Carrier Lock + Maximum Harvest → strong conventional infrastructure, reduced Tessel visibility.
- Open Chorus + Maximum Harvest → high power + high field activity, potentially volatile late state.
- Partitioned Accord + Distributed Lift → complex network of bounded support paths.

These combinations alter details, not create separate campaigns.

# Final technical audit before endgame content

Must be proven:

1. Attract/Repel prediction.
2. moving anchors.
3. Link/rescue.
4. Echo.
5. Vector Shift.
6. Flux → movement chain.
7. Phase collision/re-entry.
8. mixed-state multiplayer.
9. Invert/current relation.
10. moving kite/platform prediction.
11. session-license progression.
12. transformed world-state loading.

# Acceptance criteria

- every major ability has a unique conceptual role;
- pairwise combinations are understandable;
- no ability invalidates earlier movement;
- input budget remains viable;
- Heat/resource economy does not create waiting;
- late game recombines systems instead of adding foundational verbs;
- solo and 4P remain first-class;
- Broken Transit Crown can now be designed as mastery/convergence rather than tutorial.
