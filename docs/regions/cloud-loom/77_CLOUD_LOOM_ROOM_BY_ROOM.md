# Cloud Loom — Room-by-Room Production Specification

**Region ID:** CL  
**Coverage:** Upper Moorings → Reversal Works → Harvester Expanse → Loom Harvester → regional output decision  
**Target first-play duration:** 3–4 hours critical route; 4.5–6 hours exploratory  
**Purpose:** Greybox-ready production layout

## Global rules

- Critical route is solo-completable.
- Atmospheric currents are authored field volumes.
- No critical traversal relies on arbitrary wind simulation.
- Long falls recover quickly.
- Invert is safely taught before mandatory aerial use.
- 4P variants use multiple lanes/pairs.
- Major current/tether states reset deterministically.
- Loom Harvester retry remains under 20 seconds.

## CL01 — Skyhook Transfer

First full gas-giant vista. Safe current lane, fixed anchor, visible kite traffic. Prior Anchor choices alter distant machinery/current state.

## CL02 — Current School

Safe current-lane tutorial. Teaches entry, acceleration, edge, Repel and Vector Shift interaction. Recovery net below.

## CL03 — Sail Raptor Run

Introduces Sail Raptor. After stagger it becomes a temporary moving anchor.

## CL04 — Pressure Bell Walk

Introduces Pressure Bell and pressure pulse telegraph. Player uses cover/current rather than audio timing.

## CL05 — Mooring Village

Safe cluster with Relay, map, loadout and party services.

Primary NPCs:

- Asha Renn — route captain;
- Cor Vale — atmospheric engineer;
- Dima Kest — worker representative;
- Sen Orr — orbital analyst;
- Lio Marr — kite mechanic.

Conflict: high throughput supports the Meridian but current machinery is overstressed and worker habitats are exposed.

## CL06 — Intake Spine

Shows a one-way intake relationship that cannot yet be reversed.

Map marks:

**DIRECTIONAL FIELD — FIXED RELATIONSHIP**

## CL07 — Harvester Kite Dock

Introduces Harvester Kite. After disable it becomes a traversal platform/anchor.

## CL08 — Threader Span

Introduces Threader damaging tether. Foreshadows relationship reversal.

## CL09 — Inversion Lab

Acquire **Invert**.

Tutorial sequence:

1. reverse a short current lane;
2. invert a tether pull into push;
3. invert Harvester Kite intake/exhaust to move platform;
4. invert enemy field so it rejects its own projectile/component;
5. combine Invert + Latch/Orbit.

Optional mastery:

Repel → Vector Shift → Phase → Flux target → Latch → Invert lane → launch.

## CL10 — Reversed Spine

Immediate payoff. Revisit CL06-like structure; Invert opens shortcut, cache and upper route.

## CL11 — Pressure Ladder

First mandatory Invert traversal using vertical currents, fixed anchors and timed relationship reversal.

## CL12 — Gas Manta Crossing

Introduces Gas Manta. Fin nodes alter currents; Flux/Inversion can change the route.

## CL13 — Loom Sentinel Yard

Introduces Loom Sentinel and field-zone reversal in combat.

## CL14 — Long Catch

First signature long-distance co-op traversal.

**Solo:** Echo holds one vane while player launches.  
**2P:** one Inverts, one launches, then swap.  
**3P:** third controls moving kite/rescue.  
**4P:** two paired lanes cross midway.

Recovery returns to recent kite, not start.

## CL15 — Tether Gardens

Pressure sails on long cables. Uses tension, Invert, Orbit and optional Phase route.

## CL16 — Storm Binder Approach

Several kites change course in coordinated pattern. Elite visible ahead.

## CL17 — Storm Binder Arena

Regional elite.

Reward:

- Harvester authority key;
- Bandwidth/Module reward;
- shortcut;
- upper Loom access.

## CL18 — Broken Scoop

Cross-region state room. Foundry/Choir outcomes change power/signal conditions. Repair uses Flux + Phase + Invert.

## CL19 — Kite Relay

Signature multiplayer traversal/puzzle.

**Solo:** Echo holds one kite control.  
**2P:** split paths + Link handoff.  
**3P:** third manages current direction/rescue.  
**4P:** two pairs exchange anchor control.

## CL20 — Atmospheric Shear

High-spectacle current corridor with authored state changes. Invert is selective, not spammed.

## CL21 — Loom Convergence Chamber

## Transformation examples

**Maximum Harvest:** stronger currents, more powered machinery, faster routes, more hazards, worker areas contract.

**Stable Envelope:** calmer currents, safer traversal, some machinery dormant, worker habitats expand.

**Distributed Lift:** multiple medium-power lanes, cross-region support routes, complex external patterns, one selected earlier crisis improves.
