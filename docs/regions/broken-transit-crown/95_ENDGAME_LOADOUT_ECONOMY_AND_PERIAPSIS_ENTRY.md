# Endgame Loadout, Economy and Periapsis Entry Specification

**Purpose:** Review player power, build flexibility, rewards and finale entry so Broken Transit Crown does not become a grind wall.

# Principle

By Crown, progression should be mostly about:

- build refinement;
- mastery;
- optional capacity;
- narrative/world-state consequences.

The player should not need to farm levels or currency to be “ready.”

# Core families

All six Core families should be available through normal/exploratory play:

- Vector;
- Breaker;
- Weaver;
- Conduit;
- Mender;
- Ghost.

No seventh Core family is added.

# Bandwidth target

Recommended by Crown entry:

- critical-path player: 8–9;
- exploratory player: 9–10;
- high completion: 10–11 depending final economy.

Do not require maximum Bandwidth for critical path.

# Module philosophy

Late-game Modules should:

- sharpen a playstyle;
- improve ability combinations;
- create co-op expression.

They should not:

- fix unfair base mechanics;
- grant mandatory immunity;
- bypass core boss mechanics.

# Crown reward types

Use:

- high-tier Modules;
- Bandwidth component;
- cosmetic;
- lore/diagnostic;
- optional Periapsis support flags.

Avoid large piles of generic currency as primary late reward.

# Anchor Knight reward

Recommended:

- one high-tier Module choice from 2–3;
- small Bandwidth/capacity component;
- permanent route authorization.

# Astral Shepherd reward

Recommended:

- Periapsis Alignment Reserve;
- unique mastery Module;
- cosmetic/title;
- diagnostic.

Not required for finale.

# Convergence Prototype reward

Optional mastery reward:

- cosmetic;
- leaderboard/challenge unlock;
- flexible Module component.

Do not put best-in-slot mandatory power here.

# Respec / loadout access

Before Meridian Custodian and Periapsis:

- full loadout editing at Relay;
- no punitive respec fee;
- clear ability/Core descriptions;
- saved loadout presets recommended.

Co-op players can prepare independently.

# Consumables

If consumables survive broader design:

- finale cannot assume stockpiling;
- boss balance should not require farming;
- Relay should refill core baseline resources.

# Economy sink audit

Late-game costs should focus on:

- optional fabrication;
- cosmetics;
- convenience;
- Module variants.

Avoid mandatory expensive gate immediately before finale.

# Periapsis entry requirements

Mandatory:

- required main regional Anchor progression complete;
- Meridian Custodian resolved;
- Periapsis route physically open;
- host world-state snapshot valid.

Optional modifiers:

- Astral Shepherd Alignment Reserve;
- faction support;
- Tessel communication state;
- regional support quests;
- Convergence mastery.

No optional item is secretly mandatory.

# Periapsis State Snapshot

At BTC30 server creates/validates an authoritative snapshot containing references to:

- regional outcome tags;
- derived aggregate state;
- major faction flags;
- Tessel/Choir state;
- Shepherd flag;
- relevant support quests;
- guest session-license requirements.

This snapshot is used to configure Periapsis.

It is not an ending selection.

# Snapshot safety

Rules:

- derived values can be regenerated from authoritative choices;
- snapshot versioned;
- unknown/deprecated flags use safe fallback;
- guest personal world choices do not overwrite host campaign.

# Party entry

Host enters Periapsis with party.

Guests:

- receive required session licenses;
- keep personal unlock/reward rules;
- do not mutate host world state independently.

If party changes inside Periapsis, join policy uses safe entry points.

# Final build check

Before entering:

UI may show:

- recommended but not required preparation;
- unresolved optional quests;
- current Core/Module loadout.

Do not use “you are underleveled” if game has no level requirement.

# Difficulty

Periapsis should assume:

- complete foundational ability ownership/session access;
- competent use of at least several Core systems;
- no specific build.

Granular accessibility remains active.

# Ending prerequisites

Final configuration options can depend on:

- world state;
- quest evidence;
- faction support;
- Tessel relationship;
- optional Anchor calibration.

Requirements should be discoverable.

Avoid hidden one-missable-item endings.

# Soft-lock audit

Periapsis entry validator checks:

- valid main progression;
- required abilities licensed;
- world tags consistent;
- no impossible aggregate state;
- safe spawn;
- party ready state.

If invalid:

- return to Crown Refuge/Periapsis Gate with explicit diagnostic;
- never load into broken finale state.

# Acceptance criteria

- no grind wall;
- all Core families available;
- respec/loadout friction low;
- optional mastery rewards matter without becoming mandatory;
- Periapsis snapshot deterministic;
- guest progression rules remain intact;
- finale options arise from campaign state, not arbitrary hidden requirements.
