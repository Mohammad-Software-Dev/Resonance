# Progression Update — Flux Field to Choir Array / Phase

**Purpose:** Integrate Rust Sea and Flux into the global progression, specify backtracking value, and prepare Choir Array.

# Current major ability path

Opening:

- Attract
- Repel
- Link / Echo

Gravity Orchard:

- Latch
- Orbit

Solar Foundry:

- Vector Shift

Flooded Observatory:

- no new major movement button; mastery region

Rust Sea:

- **Flux Field**

Next:

- Choir Array → **Phase**

Then:

- Cloud Loom / late progression → Invert

# Conceptual learning progression

## Wayfarer Scar

**Move yourself.**

## Gravity Orchard

**Move relationships.**

## Solar Foundry

**Route systems.**

## Flooded Observatory

**Carry momentum through changing media.**

## Rust Sea

**Change what can respond.**

## Choir Array

**Change which state you occupy.**

This gives Phase a distinct conceptual identity after Flux.

# Flux timing

Target first-play acquisition:

- roughly 8–10 hours;
- earlier for focused players;
- later for deep explorers.

Flux should arrive after enough inert blockers have been seen that the unlock triggers strong memory.

# Flux backtracking matrix

## Wayfarer Scar

### Inert Maintenance Brace

Flux → temporary anchor → old exterior observation cache.

Reward:

- lore;
- Module/cosmetic.

### Dead Emergency Gate

Flux mechanism → shortcut to later archive route.

May combine with Phase later for deeper reward.

## Transit Spine

### Dead Rail Lattice

Flux creates temporary moving anchor route.

### Buried/disabled freight clamp

Flux allows rerouting a rail segment into optional connector.

## Gravity Orchard

### Inert Irrigation Brace

Flux anchor creates advanced canopy route.

### Root-buried machine frame

Flux exposes optional component / Convergence challenge.

Orchard outcome changes exact geometry.

## Solar Foundry

### Dead Mirror Support

Flux makes non-powered support Resonant.

Enables alternate Vector Shift route.

### Inert shutter drive

Flux lets player reposition old shutter without full Grid power.

Foundry outcome affects whether this is useful.

## Flooded Observatory

### Dry Lens Rib

Flux creates anchor between two sphere states.

### Old pressure lattice

# Backtracking design rules

Flux returns should include a mix of:

- shortcut;
- mastery route;
- lore;
- Module/Core progression;
- optional encounter;
- cross-region connector.

Do not make all returns simple one-button doors.

At least some require:

- Flux + Orbit;
- Flux + Vector Shift;
- Flux + water momentum;
- Flux + Echo/Link.

# Flux sequence expression

Advanced combo:

1. Repel launch;
2. Vector Shift;
3. Flux inert target midair;
4. Latch;
5. Orbit;
6. release into next route.

This should become a signature high-skill clip without being required on the main critical path immediately.

# Rust Sea Core/build progression

No seventh Core family is added.

Rust Sea instead broadens existing families.

## Breaker

Strong synergy with Fluxed armor/components.

## Vector

Strong synergy with Flux anchors/front movement.

## Weaver

Can support Flux relays and teammate route timing.

## Conduit

Can interact with Fluxed circuitry/projectiles.

## Mender

Supports risky front/Flux rescue.

## Ghost

Still largely unavailable until Choir/Phase.

# Rust Sea Module candidates

## Persistent Flux

Flux state lasts longer on one target.

## Ferric Wake

Successful high-speed movement over a particulate front briefly improves target acquisition on buried/Flux targets.

## Relay Flux

A valid Link interaction can extend a teammate-created Flux state modestly.

## Hard Induction

Fluxing Heavy-compatible target costs more Heat but increases useful duration.

## Quiet Induction

Flux activation creates less Ferric Hound aggro / enemy detection.

## Buried Memory

Once a hidden Flux target has been discovered, its map marker remains after leaving room.

## Reclaim Spark

Breaking a Fluxed enemy component cools a small amount of Heat.

## Field Step

First Attract/Latch to a newly Fluxed anchor has slightly improved acquisition forgiveness.

No module is mandatory.

# Flux and guest progression

If host world requires Flux and guest profile lacks it:

- grant session license under existing system.

If guest owns Flux in a pre-Rust host world:

- suppress only at protected first-play gates where it would corrupt progression;
- allow harmless use where possible.

# Flux and Echo

Echo can replay:

- Flux target activation;
- following Resonance action;
- control-node interaction.

Rules:

- recorded TargetID must remain valid;
- no dynamic retarget;
- duration/timing derives from authoritative current Flux rules, with playback validity checked.

# Flux and world transformations

Flux should interact differently with regional outcomes.

Examples:

- Excavated Rust Sea exposes more physical Flux lattice.
- Stable Tides offers more front-based Flux anchors.
- Directed Migration may create new Flux nodes outside region.

Earlier outcomes similarly alter Flux return routes.

# Choir Array setup

Rust Sea introduces signs that some “inert” systems are not merely material-response problems.

At RS32 Choirward Antenna:

- Flux can wake signal lattice;
- player detects a second overlapping field state;
- target cannot be fully interacted with in current state.

Message is:

> Flux can make the structure respond, but you still cannot occupy the state where the signal exists.

This creates desire for **Phase**.

# Phase distinction

Flux:

> change the target's Resonance eligibility.

Phase:

> change the player's field-state occupancy.

They should never feel like two keys for differently colored doors.

# Choir opening requirements

By Choir entry, player should have demonstrated:

- moving target manipulation;
- projectile routing;
- media momentum;
- Flux eligibility changes;
- multi-actor Link/Echo.

Choir can then focus on:

- state overlap;
- signal timing;
- distributed intelligence.

# Sequence breaks after Flux

Allowed:

- old-region optional route;
- early Choir side chamber;
- advanced Transit shortcut;
- collectible;
- Convergence Chamber;
- optional mini-boss preparation.

Not allowed:

- skip Phase onboarding;
- bypass Choir Prime critical narrative;
- corrupt world-state transition;
- enter late Cloud Loom progression accidentally.

# Acceptance criteria

- Flux unlock produces immediate remembered backtracking opportunities;
- earlier movement abilities remain valuable;
- Flux+movement combos have mastery ceiling;
- Rust Sea does not inflate Core taxonomy;
- session-license architecture still handles co-op mismatch;
- Choir/Phase is clearly differentiated and foreshadowed;
- backtracking rewards are varied rather than one-button gates.
