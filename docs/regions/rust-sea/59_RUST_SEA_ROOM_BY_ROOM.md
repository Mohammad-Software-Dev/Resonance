# Rust Sea — Room-by-Room Production Specification

**Region ID:** RS  
**Coverage:** Ferric Shore → Flux Works → Buried City → Dust Cathedral → regional particulate decision  
**Target first-play duration:** 3–4 hours critical route; 4.5–6 hours exploratory  
**Purpose:** Greybox-ready production layout

## Global rules

- Critical route is solo-completable.
- Rust Sea visuals may be dense; gameplay truth is sparse and readable.
- Flux-compatible targets always have authored eligibility.
- No critical route uses arbitrary particle physics.
- Flux tutorial covers traversal, combat and mechanism use before high-pressure combinations.
- 3P/4P rooms create parallel fronts/anchors/objectives rather than extra HP.
- Critical fronts and buried objects reset deterministically.
- Dust Cathedral retry remains under 20 seconds.

# Ferric Shore

## RS01 — Ironfall Transfer

**Purpose:** First Rust Sea vista and inert-lattice frustration.

Player exits Transit onto an exposed salvage gantry above the Sea.

Gameplay:

- standard movement;
- one moving particulate front below;
- one obviously useful but inert anchor lattice;
- one normal Resonant anchor for contrast.

Narrative:

- city towers are visible only as tips;
- local workers mark “tide lines” on structures.

Prior-state hooks:

- Foundry Historical may power a distant machine.
- Observatory Relief/Historic may compact one lower field band.

---

## RS02 — Ferric Strand

**Purpose:** Teach Sea surface.

A calm compacted strip is walkable.

A Flowing band crosses it.

Player learns:

- moving-surface contribution;
- dust wake;
- front edge;
- falling into deep loose Sea returns to nearby safe ledge/checkpoint rather than simulating sinking.

No enemy initially.

---

## RS03 — Dredger Wake

**Purpose:** Introduce Dredger.

Player sees disturbance before enemy emerges.

Counterplay:

- watch wake;
- force enemy into exposed state;
- use nearby normal anchor for reposition.

Lesson:

Sea surface contains information.

## RS04 — Cloudmouth Ridge

**Purpose:** Introduce Cloudmouth and particle armor.

Cloudmouth assembles armor from nearby particulate.

Player can break conventional armor but sees an inert lattice node underneath that does not respond yet.

This is deliberate Flux foreshadowing.

**Purpose:** Regional settlement/safe cluster.

- salvage exchange;

- Ressa Korr — tide-reader / route master;

## RS08 — Ferric Hound Run

**Purpose:** Introduce Ferric Hound.

## RS09 — Flux Foundry

**Purpose:** Acquire **Flux Field**.

Fiction:

An old material-conditioning station can induce temporary Resonant alignment in low-response lattice.

Nox Arrel helps adapt the process to Wayfarer rigs.

### Tutorial 1 — Target

Flux inert anchor.

Then Attract/Latch to it.

### Tutorial 2 — Duration

Flux a bridge support, cross before decay.

### Tutorial 3 — Combat

Flux Cloudmouth exposed lattice component → pull armor/core.

### Tutorial 4 — Mechanism

Flux buried control node → activate field lift.

### Optional mastery

Jump → Vector Shift → Flux target midair → Latch → Repel.

Safe reset room.
