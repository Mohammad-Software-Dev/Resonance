Target acquisition:

- roughly 10–14 hours on typical first play;
- earlier for focused routes;
- later for completionist exploration.

- Phase barriers;

# Ghost Core

Choir introduces/deepens **Ghost Core**.

Identity:

- Phase precision;
- evasion;
- state counterplay;
- repositioning.

Any Wayfarer can equip it.

## Baseline candidate

A well-timed Phase transition through a compatible attack reduces Phase recovery slightly.

No universal invulnerability.

## Technique candidate — Ghost Return

After exiting Phase near a valid enemy/state interaction, next evade or movement action gains limited recovery benefit.

Must not become mandatory defensive meta.

# Choir Module candidates

## Phase Link

Maintain one Link across a state boundary briefly.

## Signal Memory

A received Signal Token persists slightly longer during movement.

## Ghost Step

Phase re-entry preserves more horizontal momentum.

## Quiet Carrier

Phase transition generates less enemy state-tracking pressure.

## Resonant Grip

Latch acquisition to Resonant-only anchor is slightly more forgiving.

Echo signal interaction window slightly longer.

## Split State

No Module required for critical route.

# Choir → Cloud Loom setup

CA33 reveals an atmospheric field relationship whose **direction** is the problem.

Phase allows player to occupy its state.

Flux can activate the relevant structure.

But neither can reverse it.

The player sees:

- wind/field lane pulling the wrong way;
- harvester machinery locked by directional relationship;
- Tessel signal attempting to route around it.

This creates desire for **Invert**.

# Invert distinction

Flux:

> change target eligibility.

Phase:

> change player state occupancy.

Invert:

> reverse a selected field relationship.

Examples:

- attraction ↔ repulsion;
- flow lane direction;
- harvester pressure relationship;
- enemy field relation.

Invert must not be “Phase but red.”

# Cloud Loom expected movement composition

By entry, player can:

- Attract/Repel;
- Link/Echo;
- Latch/Orbit;
- Vector Shift;
- Flux;
- Phase.

Cloud Loom can therefore focus on:

- long exterior movement;
- moving aerial platforms;
- wind/field direction;
- Invert;
- multi-lane co-op.

# Session-license behavior

If host requires Phase and guest lacks permanent unlock:

- grant session license.

If guest owns Phase in pre-Choir host world:

- suppress only protected progression-breaking interactions;
- harmless Phase movement may remain available where safe.

# Echo + Phase

Echo records state transitions.

Later:

- Phase Link upgrade may permit more complex Echo/human cross-state choreography.

Keep baseline puzzles understandable.

# Sequence breaks after Phase

Allowed:

- optional Cloud Loom outskirts;
- old-region shortcuts;
- advanced Convergence Chambers;
- optional mini-boss preparation;
- lore/Tessel interactions.

Not allowed:

- skip Invert acquisition;
- bypass Loom Harvester critical setup;
- enter Broken Transit Crown progression improperly;
- invalidate Choir outcome.

# All six Core families

By Choir completion, exploration can expose all six:

- Vector;
- Breaker;

- Mender;
- Ghost.

Late progression should now deepen Core identities rather than add more families.

# Acceptance criteria

- Phase unlock creates remembered returns;
- Phase+Flux combinations feel richer than either alone;
- Ghost Core adds optional build identity;
- backtracking is varied;
- Choir outcome matters later without tripling content;
- Invert is clearly foreshadowed and mechanically distinct;
- session-license architecture still handles progression mismatch;
- no late movement combination requires architecture rewrite.
