# Iteration 3F — Choir Array Production Brief

**Status:** Production-specification pass  
**Scope:** Choir Array gameplay, Phase acquisition, room flow, standing-wave systems, enemies, Dissonant Pair, Choir Prime, Tessel reveal, regional transformation, assets, accessibility, networking/performance and progression into Cloud Loom  
**Version 1 assumptions:** 2.5D, PC-first, solo + 1–4 online co-op, Unreal Engine 5.8.x, host-authoritative listen server

## Purpose

Choir Array is the first region where Resonance stops being explainable as only machinery, ecology or malfunction.

Regional identity:

> **Phase changes which field-state the player can occupy and affect.**

Choir Array must not become a rhythm game and must not create a duplicated “shadow world.”

Instead, the region uses:

- overlapping interaction states;
- standing-wave signal infrastructure;
- state-dependent topology;
- Phase-compatible enemies;
- Link-based signal routing;
- distributed field life.

Every timing mechanic has visual equivalents.

## Canon carried forward

- Choir Array is a network of communication towers and standing-wave systems.
- Phase is the major ability milestone.
- Choir Prime is the regional major boss.
- Dissonant Pair is the regional elite.
- Enemies include Tone Shade, Harmonic Knot, Pulse Cantor, Null Listener, Echo Husk and Chorus Bloom.
- Rhythm/audio cues always have visual equivalents.
- Four players may manage multiple network sections simultaneously.
- Tessel / distributed field intelligence becomes undeniable here.
- Ghost Core is introduced/deepened around Phase/evasion.
- Cloud Loom / Invert follows later.

## Regional fantasy

Choir Array was originally a communications and synchronization network.

It contained:

- long-range signal towers;
- distributed timing arrays;
- station-wide calibration systems;
- emergency coordination channels;
- field-state measurement infrastructure.

After the Meridian fractured:

- standing waves became self-sustaining;
- signal loops persisted without normal transmitters;
- pattern memory accumulated;
- some interactions began adapting to observers;
- semi-physical forms emerged at repeated interference nodes.

Residents learned to live around “choir weather” long before anyone could prove it was intelligent.

## Narrative milestone

Choir Array should move the player from:

> “Some Resonance systems behave strangely.”

to:

> “Something distributed is perceiving, remembering and responding.”

Tessel is not introduced as a humanoid AI speaking from a terminal.

The first undeniable evidence comes from coordinated behavior across physically separated nodes that:

- shares information faster than local mechanisms can explain;
- responds to player choices;
- reproduces altered patterns;
- communicates meaning through routing/state rather than exposition.

## Core systems

### 1. Phase State

Player can temporarily shift between:

- **Material State** — ordinary world interaction;
- **Resonant State** — alternate field interaction.

This changes:

- valid collision layers;
- target eligibility;
- enemy vulnerability;
- signal interaction;
- selected route topology.

It does not move the player to a duplicate level.

### 2. Standing-Wave Networks

Signal networks use deterministic node graphs.

Nodes may:

- emit;
- receive;
- relay;
- invert timing;
- split;
- synchronize;
- store a short state.

The player manipulates them through Resonance, Link and Phase.

### 3. Signal Timing

Signals operate in authored windows.

Timing is communicated through:

- expanding rings;
- node animation;
- light pattern;
- geometry pulse;
- optional audio.

No required mechanic depends on hearing.

### 4. Phase-Compatible Topology

Selected structures may exist in:

- Material only;
- Resonant only;
- both;
- one state but with different behavior.

Examples:

- a barrier is solid only in Material;
- an anchor exists only in Resonant;
- a bridge has different collision in each state;
- an enemy can attack from one state and be vulnerable in another.

### 5. Link Signal Transmission

Link can carry a limited signal state between valid nodes/players.

Baseline rule:

- Link carries signal only while endpoints are in compatible Phase states unless a relay node bridges states.

Later upgrade candidate:

- Phase Link allows short cross-state persistence.

## Phase acquisition role

Phase is Tier 4 — State Mastery.

Before Phase:

> “I can make more things respond using Flux.”

After Phase:

> “I can occupy the state in which some structures and entities actually exist.”

Flux changes the target.

Phase changes the player’s state relationship.

## Region structure

### Act A — Silent Reaches

Teach:

- standing-wave visibility;
- signal timing;
- Tone Shade;
- Phase-inaccessible routes.

### Act B — Phase Chamber

Acquire Phase.

Teach:

- state shift;
- pass selected barrier/hazard;
- attack state-dependent enemy;
- phase-only anchor;
- Link/signal compatibility.

### Act C — Harmonic Array

Combine:

- Phase;
- Flux;

- Dissonant Pair;

### Act D — Prime Chorus

Choir Prime tests distributed network management and Phase.

Afterward, the party chooses how the Array should interact with Tessel and the wider Meridian.

## Duration target

- critical route: 3–4 hours;
- exploratory route: 4.5–6 hours.

Choir is a major narrative region and can be slightly denser in optional story spaces.

## Regional stabilization decision

### Option A — Carrier Lock

Force the Choir Array back into a narrow historical communications band.

Benefits:

- stable long-range Relay communication;
- fewer Phase anomalies in older regions;
- Custodian-compatible infrastructure becomes more reliable.

Costs:

- much distributed field-life expression becomes suppressed/inaccessible;
- some Phase routes disappear;
- Tessel interprets the action as containment.

### Option B — Open Chorus

Allow the distributed standing-wave network to persist and communicate widely.

Benefits:

- Tessel/field entities become visible and communicative across the Meridian;
- new Phase routes/signals appear;
- richer field-network information.

Costs:

- more anomalous entities/phenomena appear in old regions;
- some conventional systems suffer interference;
- Custodian response escalates.

### Option C — Partitioned Accord

Requires optional network-mapping / communication quests.

Create bounded communication partitions and negotiated relay paths.

Benefits:

- some infrastructure remains stable;
- field-life communication survives;
- selected regions gain controlled Phase channels.

Costs:

- complex maintenance;
- neither historical network nor Tessel receives unrestricted access;
- failures can create dangerous isolated interference pockets.

It is not a “perfect compromise.” It creates new constraints.

## Cross-region consequences

At minimum:

- Relay behavior changes in Transit / Wayfarer Scar.
- Phase-visible entities/routes appear or disappear in earlier regions.
- Rust Sea signal anomalies change.
- Foundry/Observatory diagnostic systems receive new data/interference.
- Cloud Loom access/state is affected.

## Co-op principles

Choir Array should be one of the strongest co-op regions.

Examples:

- players occupy different Phase states;
- one routes signal while another traverses state-specific path;
- Link transfers timing/state;
- two pairs manage different network branches;
- one player acts as Phase-state scout while another stabilizes Material node.

No player should become permanent “metronome holder.”

## Solo Echo

Echo may reproduce:

- Phase transitions;
- signal-node interaction;
- Link-compatible state where explicitly supported;
- movement path.

Echo must use recorded state and TargetIDs.

It does not dynamically solve signal timing.

## Ghost Core

Choir Array introduces/deepens **Ghost Core**.

Identity:

- Phase;
- evasion;
- state transition;
- precise counterplay.

It must remain optional.

## Quality gates

### Phase

Within 20 minutes of acquisition, player uses Phase for:

- traversal;
- combat;
- puzzle/network interaction.

### Accessibility

A deaf player or player with audio reduced to zero must be able to complete every critical signal mechanic.

### Identity

Blind footage should read as:

> “the standing-wave / overlapping-state region”

—not “music level” or “ghost level.”

### Tessel

The player should leave believing distributed field intelligence is real, while still having unanswered questions about:

- scope;
- motives;
- individuality;
- danger.

### Four-player

At least one:

- traversal sequence;
- signal-routing puzzle;
- Dissonant Pair phase;
- Choir Prime phase

must make four-player coordination meaningfully better, not merely busier.

## Exit criteria

Iteration 3F is complete when:

- Choir Array is greybox-ready;
- Phase has a safe tutorial path;
- Phase remains conceptually distinct from Flux;
- signal mechanics are deterministic and accessible;
- Choir Prime works for 1–4 players;
- Tessel reveal is coherent with prior foreshadowing;
- regional decision changes communication/Phase visibility elsewhere;
- old-region Phase returns are specified;
- no mechanic requires a duplicate-world simulation;
- Cloud Loom / Invert setup is coherent.
