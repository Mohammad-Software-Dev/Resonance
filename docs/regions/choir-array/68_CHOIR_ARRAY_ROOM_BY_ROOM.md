# Choir Array — Room-by-Room Production Specification

**Region ID:** CA  
**Coverage:** Silent Reaches → Phase Chamber → Harmonic Array → Choir Prime → regional stabilization decision  
**Target first-play duration:** 3–4 hours critical route; 4.5–6 hours exploratory  
**Purpose:** Greybox-ready production layout

## Global rules

- Critical route is solo-completable.
- Phase is taught safely before lethal state-dependent traversal.
- Every critical signal mechanic has visual timing parity.
- No critical route requires hearing.
- Phase-compatible geometry is authored explicitly; no duplicate-world simulation.
- 3P/4P content adds parallel state/network responsibility rather than HP.
- Critical signal networks reset in 2–4 seconds after normal failure.
- Choir Prime retry remains under 20 seconds.
- Tessel reveal is paced through behavior first, exposition second.

# Silent Reaches

## CA01 — Dead Carrier Approach

**Purpose:** Establish silence, scale, and inaccessible alternate-state structures.

Gameplay:

- standard traversal;
- dormant antenna ribs;
- visible but non-interactable translucent structure;
- one signal pulse moving through background infrastructure.

Player sees an anchor-like object that target acquisition rejects.

Map marks:

**FIELD-STATE MISMATCH — RESPONSE DETECTED**

No Phase yet.

---

## CA02 — Standing Wave Walk

**Purpose:** Teach signal timing without Phase.

A low-risk standing wave sweeps a corridor.

Telegraphs:

- expanding visual ring;
- floor-node pulse;
- optional tone.

Player crosses between windows.

No rhythm input; the challenge is reading state progression.

---

## CA03 — Tone Shade Gallery

**Purpose:** Introduce Tone Shade.

Tone Shade alternates:

- Material-present / vulnerable;
- Resonant-present / untouchable to player.

Without Phase, player must attack during Material exposure.

This establishes that some enemies occupy more than one state.

---

## CA04 — Relay Spine

**Purpose:** Teach deterministic signal graph.

Player manipulates:

- one emitter;
- one relay vane;
- one receiver.

Attract/Repel rotates the vane between authored states.

Receiver opens door.

Signal path is readable visually.

---

## CA05 — Listener's Rest

**Purpose:** First safe social/research cluster.

Services:

- Relay/save;
- map;
- loadout;
- local signal diagnostics;
- party management.

NPCs:

- Ena Vos — field linguist;
- Teren Kael — Relay engineer;
- Mira Sen — resident signal-tender;
- Olan Dey — Custodian-trained communications technician;

Residents distinguish between:

No one can yet prove intelligence.

# Phase Chamber

## CA06 — Null Listener Test

**Purpose:** Introduce Null Listener before Phase.

Enemy creates local Link-suppression zone.

Player learns:

- suppression is spatial/telegraphed;
- normal movement remains available;
- Link is not universally reliable.

This prepares later cross-state Link rules.

---

## CA07 — Memory Relay

**Purpose:** Show signal storing/recall.

A Memory Node holds one pulse briefly.

Player:

1. sends pulse;
2. traverses to receiver;
3. triggers release.

This teaches delay without rhythm-game timing.

---

## CA08 — Unreachable Bridge

**Purpose:** Make Phase desire explicit.

A Resonant-state bridge is visible as intermittent field trace.

Player can inspect:

**OVERLAPPING STRUCTURE — LOCAL STATE INCOMPATIBLE**

Alternate side route leads onward.

---

## CA09 — Phase Calibration Chamber

**Purpose:** Acquire **Phase**.

Fiction:

Old Choir maintenance rigs could briefly enter the Array's calibration state to service signal structures that did not fully exist in ordinary material interaction.

Teren Kael / Ena Vos helps adapt the field process to the Wayfarer rig.

### Tutorial 1 — State shift

Phase through a Material-solid / Resonant-passable barrier.

### Tutorial 2 — Resonant bridge

Enter Resonant State and stand on a bridge absent in Material.

### Tutorial 3 — Phase anchor

Phase → Latch to Resonant-only anchor → return safely.

### Tutorial 4 — Combat

Tone Shade shifts state; player Phases to attack during Resonant interval.

### Tutorial 5 — Re-entry safety

A blocked return example demonstrates the warning/safe-return behavior without killing the player.

### Optional mastery

Repel → Vector Shift → Phase midair → Latch Resonant anchor → Flux inert node after landing.

---

## CA10 — Rewritten Bridge

**Purpose:** Immediate local backtracking payoff.

Return near CA08.

Phase opens:

- direct bridge;
- optional side cache;
- first Phase+Flux combination target.

The player should immediately remember older state-mismatch blockers.

## CA15 — Echo Husk Theatre

**Purpose:** Introduce Echo Husk.

The enemy records one simplified recent player action.

Examples:

- jump line;
- Repel pulse;

- Phase shift.

- bait harmless action;
- change route;
- use enemy replay against another target.

This foreshadows Tessel's observation/memory without claiming full personhood.

## CA19 — Fourfold Relay

**Purpose:** Signature multiplayer signal-routing puzzle.

Four network sections connect to a central receiver.

### Solo

Two branches handled sequentially; Echo holds one stored branch during final overlap.

### 2P

One branch per player, then cross-Link handoff.

### 3P

Two branch players + one Bridge Node / moving receiver role.

### 4P

Each player can begin on one section, but network intentionally cross-connects so responsibility shifts through Link rather than staying assigned.

No one stands idle on a receiver.

---

## CA20 — The Answering Pattern

**Purpose:** First undeniable Tessel behavior.

The player routes a calibration pulse.

The network replies with a pattern that:

1. repeats the player's route;
2. alters one node;
3. sends a pulse to a physically separate tower not connected by the active network;
4. that tower responds with a meaningful repeated structure associated with the party's earlier actions.

The event is reproducible and cannot be explained by local automation alone.

No voice says “I am Tessel.”

Ena/Olan disagree over interpretation.

# Transformation examples

## Carrier Lock

- fewer Resonant-only structures remain visible;
- Material routes become more stable;
- Relay service improves;
- Tone Shade/field entities become rarer in lower Array.

## Open Chorus

- more Resonant routes/entities appear;
- signal networks become richer;
- conventional Relay noise/interference increases;
- optional Tessel paths open.

## Partitioned Accord

- selected corridors remain Material-stable;
- designated Phase channels open;
- isolated interference pockets become new hazard/challenge spaces.
