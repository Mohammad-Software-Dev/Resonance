# Campaign-Wide Contradiction and Soft-Lock Audit

**Purpose:** Audit the Version 1 critical design from opening to credits for logical, progression and state contradictions.

# Locked critical progression

Opening:

- Attract;
- Repel;
- Link/Echo.

Gravity Orchard:

- Latch;
- Orbit.

Solar Foundry:

- Vector Shift.

Flooded Observatory:

- mastery/build depth, no major movement unlock.

Rust Sea:

- Flux.

Choir Array:

- Phase.

Cloud Loom:

- Invert.

Broken Transit Crown:

- mastery/convergence, no new foundational ability.

Periapsis:

- final reconfiguration, no new foundational ability.

This progression is internally coherent.

# Ability contradiction audit

## Flux vs Phase

Distinct:

- Flux changes target eligibility.
- Phase changes player state occupancy.

Pass.

## Phase vs Invert

Distinct:

- Phase changes state occupancy.
- Invert reverses relationship.

Pass.

## Invert vs Attract/Repel

Invert does not swap player input globally.

Pass.

## Link vs environmental tethers

Visual and gameplay language must remain distinct.

Requires UI/VFX validation.

## Echo

Echo remains deterministic recorded proxy and never becomes general AI.

Pass.

# Major progression soft-lock rules

Every critical gate must have:

- ability/session-license validation;
- stable TargetID/RelationshipID;
- reset path;
- recovery route.

Guests can always receive required session licenses for host-world progress.

# Region-choice contradiction audit

Regional outcomes can alter later content but must not remove all critical progression.

Rule already established and preserved through Periapsis.

# Finale availability audit

Historical Continuity:

- always available.

Distributed Meridian:

- always available.

Therefore every valid campaign can finish.

Open Resonance:

- conditional but recoverable through visible Tessel-channel work.

Bounded Accord:

- conditional advanced path with multiple substitute prerequisite routes.

Pass.

# Hidden ending audit

No final configuration requires:

- one missable collectible;
- one specific character;
- one specific co-op party size;
- inaccessible post-choice content without warning.

Pass.

# Boss-order audit

Mandatory late sequence:

- Loom Harvester;
- Anchor Knight;
- Meridian Custodian;
- Anchor Zero;
- chosen Final Configuration Encounter.

Astral Shepherd optional.

This avoids excessive mandatory boss stacking.

# Narrative contradiction audit

## Tessel

Known:

- distributed field intelligence exists;
- remembers/adapts/communicates.

Unknown:

- singular/plural identity;
- origin;
- memory boundaries;
- ultimate goals.

Finale does not require resolving these facts.

Pass.

## Custodians

Remain technically/politically credible even after boss defeat.

Pass.

## Gas giant

Locked and integrated with Cloud Loom/Periapsis.

Pass.

# World-state aggregation audit

Use six derived state groups plus explicit support flags.

No global morality score.

Pass.

# Save-state audit

Irreversible choices:

- regional host-owned decisions;
- final configuration.

All require authoritative save/transaction boundaries.

Finale preserves pre-commit state.

Pass conceptually.

# Co-op audit

Version 1 supports:

- solo;
- 2P;
- 3P;
- 4P;

from the start.

No couch/split-screen.

No critical design assumes later retrofit.

Pass.

# Solo audit

Echo must support every required simultaneous mechanic.

No critical puzzle requires:

- dynamic AI improvisation;
- two independent combat agents;
- unbounded Echo scripting.

Pass conceptually; production validation required.

# Four-player audit

Avoid:

- single narrow anchor stack;
- one switch-holder;
- unreadable VFX;
- pure HP scaling.

Regional specs consistently use lanes/pairs/subsystems.

Pass conceptually.

# Accessibility audit

Critical design consistently supports:

- visual equivalents for audio;
- target/timing assists;
- reduced VFX/camera motion;
- damage tuning.

No ending/boss excludes assist users.

Pass.

# Economy audit

No mandatory grind wall before Crown/Periapsis.

All Core families available.

No optional superboss grants required power.

Pass.

# Potential unresolved production risks

These remain engineering/playtest risks rather than design contradictions:

1. controller/input complexity with complete toolkit;
2. Attract/Repel prediction under latency;
3. moving-platform prediction;
4. Flux → movement chain latency;
5. Phase collision/re-entry;
6. Invert relationship timing;
7. Echo reliability;
8. four-player readability;
9. world-state variant QA size;
10. finale branch test matrix.

# Content consistency tasks for consolidation

Older documents may still contain:

- preliminary boss names;
- preliminary ending path descriptions;
- earlier wording that treats Astral Shepherd as critical;
- old “Pale Engine” working name;
- provisional ability timing.

Iteration 3J should reconcile/supersede these in the canonical index and key bibles rather than silently leaving contradictions.

# Soft-lock validator requirements

Automated graph validation should test:

- each legal regional outcome set;
- host/guest ability mismatch;
- optional boss incomplete;
- all final configuration prerequisite states;
- pre/post-final commit save;
- room reset states.

# Acceptance criteria

- at least two finale configurations always available;
- no ability contradiction blocks progression;
- no character/party-size gate;
- no hidden one-item ending requirement;
- mandatory boss pacing is reasonable;
- known remaining issues are production risks, not unresolved game logic.
