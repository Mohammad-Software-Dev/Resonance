# Broken Transit Crown — Room-by-Room Production Specification

**Region ID:** BTC  
**Coverage:** transformed Transit return → Crown Fracture → Custodian Assembly occupation → Meridian Custodian → Periapsis gate  
**Target first-play duration:** 3–4 hours critical route; 5–7 hours with Astral Shepherd/optional content  
**Purpose:** Greybox-ready late-game mastery topology

## Global rules

- No new foundational movement ability.
- Critical rooms use 2–3 primary verbs at once, not the whole toolkit continuously.
- Old Transit landmarks are visually recognizable.
- Every derived world-state combination preserves one critical route.
- Custodian counters are telegraphed and temporary.
- Solo Echo remains valid.
- 4P routes use paired/multi-subsystem responsibility.
- Major retries <20 seconds.

# Act A — Return to the Spine

## BTC01 — Scar Return

A late-game re-entry into the region near the opening Transit approach.

Recognizable:

- old tutorial rail;
- damaged Relay mast;
- first early-game force-training structure.

Changed:

- rail is detached;
- current from Cloud Loom crosses space;
- one Phase trace overlays old wall;
- Custodian markers designate restricted zone.

Purpose: immediate emotional contrast.

## BTC02 — First Rail Reversal

Old rail tug mechanism is now misaligned.

Required:

- Flux inert clamp;
- Invert rail relation;
- Latch to moving carriage.

No enemy. Tests late ability composition safely.

## BTC03 — Relay Under Occupation

Old Relay is recognizable but Custodian-controlled.

Encounter:

- Custodian Surveyor;
- Anchor Suppressor;
- one ordinary security unit.

Player learns suppression marks affected anchors, alternate routes remain valid, and Flux/Phase can bypass selected control.

Relay becomes usable after encounter.

## BTC04 — Tutorial Hall Rotated

A direct callback to an early movement room, now rotated/exposed.

Uses Orbit, Vector Shift and the atmospheric-support variant.

World-state differences:

- Maximum Harvest: strong fast current shortcut/hazard.
- Stable Envelope: calmer but longer route.
- Distributed Lift: two medium routes.

## BTC05 — Crown Refuge

Safe cluster with Relay, loadout, state diagnostic wall, surviving Transit workers, neutral/skeptical Custodian contact and party services.

Critical fact: Custodian Assembly occupies upper Crown and is preparing forced Periapsis alignment.

# Act B — Crown Fracture

## BTC06 — Split Platform Yard

Two detached Transit platforms move on old rail relationships.

Core verbs:

- Latch/Orbit;
- Invert;
- Link/Echo.

2P/4P can control separate lanes.

## BTC07 — Locked Anchor School

Custodian Anchor Suppressor locks the player's recently repeated anchor category for a short time.

Counterplay:

- switch route;
- Phase;
- Flux alternate anchor;
- attack suppressor.

First explicit “adapt your habit” lesson.

## BTC08 — Phase Relay Scar

Old Relay architecture has a Resonant-state component, not a duplicate room.

Player:

- Phases to bridge a broken section;
- Fluxes an inert relay;
- returns Material to operate physical rail.

Choir outcome changes signal stability.

## BTC09 — Flooded Service Loop

Observatory state affects water/pressure remnant.

Critical path always works; optional route changes.

## BTC10 — Foundry Power Junction

Foundry outcome affects power reserve and machine activity.

Player uses beam/conduit machinery, Flux, Invert and combat.

- Historical: more powered hazards and shortcuts.
- Civic: fewer hazards, more worker support.
- Spectrum: Phase/Choir anomaly route.

## BTC11 — Rust Fracture

Rust outcome alters a broken freight section.

Uses:

- Flux;
- hidden anchor;
- current/rail movement.

Excavation / Tides / Migration alter geometry and enemy type.

## BTC12 — Anchor Knight Approach

Shows disabled Wayfarer-style anchors embedded in Custodian barricades.

Optional overlook telegraphs elite behavior.

## BTC13 — Anchor Knight Arena

Regional elite.

Reward:

- Crown authorization key;
- high-tier Module/Bandwidth reward;
- permanent shortcut;
- Custodian countermeasure data.

## BTC14 — Pairline Traverse

Signature co-op traversal.

Two moving rail arcs cross a Phase-only bridge.

- Solo: Echo holds one rail relationship.
- 2P: one per rail, then Link handoff.
- 3P: third manages suppressor/rescue.
- 4P: two pairs on separate arcs, exchanging control midway.

## BTC15 — Broken Relay Swarm

Optional mini-boss/encounter candidate.

# World-state variant policy

Critical route changes in **quality and tactics**, not existence.

Examples:

- high Power Reserve: more moving machinery, shortcuts, hazards;
- low Power Reserve: more Flux/manual routes;
- Open Field Communication: more Phase entities/routes;
- Carrier Lock: cleaner conventional Relay path;
- high Atmospheric Support: stronger current shortcuts;
- Stable Envelope: safer but slower exterior route;
- Rust Excavation: more exposed structural paths;
- Stable Tides: more particulate-front options.

# Greybox acceptance

- at least 12 recognizable old Transit landmarks/structures;
- critical path survives every legal aggregate state;
- full toolkit receives meaningful use;
- no room requires all abilities simultaneously;
- Anchor Knight, Shepherd and Meridian Custodian reset correctly;
- optional Shepherd never gates Periapsis;
- 1/2/3/4P routes valid;
- late join reconstructs world-state variants;
- boss retries <20 sec;
- Periapsis snapshot created without mutating final ending state.
