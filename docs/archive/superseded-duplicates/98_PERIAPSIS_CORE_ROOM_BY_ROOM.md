# Periapsis Core — Room-by-Room Production Specification

**Region ID:** PC  
**Coverage:** Crown Gate → Anchor Zero → Configuration Forum → final path → commit/credits  
**Target first-play duration:** 2.5–4 hours depending configuration and optional exploration  
**Purpose:** Greybox-ready final-region topology

## Global rules

- No new foundational ability.
- All critical routes work solo and 1–4 online co-op.
- Periapsis reads world-state variants before dangerous traversal.
- No ending choice is hidden inside a combat interaction.
- Final configuration is selected explicitly after projections.
- Long dialogue is skippable on retry.
- Boss retry paths remain short.

# Shared Act A — State Descent

## PC01 — Crown Gate Descent

Transition from BTC30.

Shows:

- Broken Crown above;
- Periapsis machinery below;
- multiple regional Anchor lines converging.

Server validates world-state snapshot and session licenses.

## PC02 — Orientation Spine

First gravity-orientation room.

Uses known traversal only.

Three authored orientations rotate as Anchor Zero cycles.

No new gravity-control input.

## PC03 — State Lattice

Six subsystem displays represent:

- Power;
- Water/Thermal;
- Structural;
- Field Communication;
- Atmospheric;
- Habitat/Adaptation.

Each shows current condition through environment and concise diagnostics.

## PC04 — Support Concourse

Regional/faction support appears according to prior choices.

Possible representatives:

- Foundry technicians;
- Observatory hydrologists;
- Rust salvagers;
- Choir mediators/Tessel channel;
- Loom crews;
- Custodian technical staff.

Target 2–4 active support groups, not everyone at once.

## PC05 — Wayfarer Staging Ring

Relay/loadout/save.

Each active Wayfarer receives a short final pre-Anchor-Zero beat.

No character is mechanically required.

# Shared Act B — Anchor Zero Petals

## PC06 — Power Petal

Route variant by Power Reserve.

High power:

- more active machinery;
- faster routes;
- stronger hazards.

Low power:

- dead systems;
- Flux/manual routing;
- lower hazard density.

## PC07 — Thermal Petal

Water/Thermal state drives coolant, heat, pressure and optional water-volume routing.

## PC08 — Structural Petal

Rust/structural state drives exposed support ribs, buried/inert paths and heavy moving components.

## PC09 — Signal Petal

Choir state drives clean Relay, Open Chorus manifestations, or bounded Phase channels.

Critical route remains equivalent in difficulty envelope.

## PC10 — Atmospheric Petal

Loom state drives current strength, safe lanes and distributed support currents.

## PC11 — Adaptation Petal

Shows how transformed communities/ecologies now couple into Periapsis support.

This is not a morality gauge.

Examples:

- adaptive bio-structures damp vibration;
- historic infrastructure provides rigid support;
- mixed state uses both with tradeoffs.

## PC12 — Alignment Matrix

All six petals feed one central matrix.

Player performs a mastery sequence using 3–4 mechanics selected by current state.

Purpose:

- prove systems are connected;
- unlock Anchor Zero.

## PC13 — Anchor Zero Antechamber

Relay, diagnostics and boss explanation.

Astral Shepherd Alignment Reserve appears here if owned.

Retry <20 seconds.

## PC14 — Anchor Zero

Major reconfiguration boss/system.

## PC15 — Neutral Zero

Post-boss quiet space.

Anchor Zero is temporarily in neutral governance state.

The player can inspect:

- system projections;
- available configurations;
- known costs;
- missing prerequisites.

Save created here.

# Shared Act C — Configuration Forum

## PC16 — Configuration Forum

Explicit selection interface in-world.

Available choices:

- Historical Continuity;
- Distributed Meridian;
- Open Resonance if Tessel channel viable;
- Bounded Accord if prerequisites met.

Guests cast advisory votes.

Host selects a path to preview.

Selection is **not yet irreversible**.

## PC17 — Projection Walk

Chosen configuration produces a short projection route showing:

- likely regional effects;
- primary sacrifices;
- support/faction reaction;
- technical risks.

Player can return to PC16 and inspect another available configuration.

## PC18 — Final Commit Threshold

Party enters the selected configuration branch.

The branch remains cancelable until the actual **Commit Node** near its final encounter.

A save is created before irreversible commit.

# Historical Continuity branch

## PC19H — Central Bus

Rebuild historical master-control lanes.

Uses conventional power, moving rails and Invert/Flux as repair tools.

## PC20H — Containment Ring

Tessel/field manifestations push against narrowing communication bands.

Player preserves infrastructure while sealing unstable field spillovers.

## PC21H — Continuity Encounter

Path-specific final encounter.

## PC22H — Continuity Commit

Irreversible choice:

Anchor Zero returns as centralized coordinator.

# Distributed Meridian branch

## PC19D — Regional Bus

Anchor Zero is split into regional control relationships.

Player routes support through multiple Anchor networks.

## PC20D — Cascade Web

Central systems begin failing because they are losing master coordination.

Player stabilizes decentralized sectors while intentionally allowing some historical systems to shut down.

## PC21D — Distribution Encounter

Path-specific final encounter.

## PC22D — Distribution Commit

Irreversible choice:

master control is permanently dispersed.

# Open Resonance branch

## PC19O — Tessel Interface

Requires viable field channel.

Players occupy mixed Material/Resonant infrastructure and establish communication.

## PC20O — Shared Carrier

Human/Custodian systems and Tessel field nodes attempt to synchronize.

Unstable behavior must be managed without suppressing the network.

## PC21O — Resonance Encounter

Path-specific final encounter.

## PC22O — Resonance Commit

Irreversible choice:

Tessel becomes part of habitat regulation.

# Bounded Accord branch

## PC19B — Partition Matrix

Requires all Accord prerequisites.

Players construct bounded control partitions.

## PC20B — Sacrifice Bus

The player must deliberately take Anchor Zero's future master-control pathways offline to prevent either side from dominating the network.

The cost is explicit before action.

## PC21B — Accord Encounter

Path-specific final encounter.

## PC22B — Accord Commit

Irreversible choice:

Anchor Zero is permanently decommissioned as master controller; bounded distributed governance takes over.

# Shared Act E — Aftermath

## PC23 — Stabilization View

Short controllable aftermath showing immediate orbital stabilization state.

## PC24 — Wayfarer Final Ring

Final Wayfarer beats.

Dialogue varies by chosen configuration and earlier decisions.

## PC25 — Regional Echoes

Montage/interactive projections of 4–6 representative regional outcomes based on world state.

## PC26 — Credits Threshold

Final departure/observation moment.

Credits begin.

# Post-completion utility spaces

## PC27 — Configuration Archive

Accessible from pre-commit Continue state after first completion.

Tracks:

- completed configuration(s);
- epilogue summaries;
- optional mastery records.

## PC28 — Zero Diagnostic Vault

Optional Anchor Zero lore and multiple historical configuration modes.

May gain extra data from Astral Shepherd.

## PC29 — Final Convergence Challenge

Optional post-completion/pre-commit mastery challenge.

No ending gate.

## PC30 — Periapsis Observation Deck

Quiet optional space for party screenshots/conversation before final commit.

# Co-op rules

## 1P

Echo handles one simultaneous subsystem.

## 2P

Paired controls.

## 3P

Pair + flex/rescue/stabilization.

## 4P

Two pairs or four subsystem positions.

No final configuration requires a specific character.

# Greybox acceptance

- all legal world-state snapshots reach PC15;
- Anchor Zero resets;
- all available configurations preview correctly;
- unavailable paths explain missing prerequisites;
- each final branch has mechanically distinct objective;
- Commit Node is explicit;
- retry skips long dialogue;
- host/guest authority is unambiguous;
- post-completion Continue returns to pre-commit state;
- credits/completion record cannot corrupt campaign save.
