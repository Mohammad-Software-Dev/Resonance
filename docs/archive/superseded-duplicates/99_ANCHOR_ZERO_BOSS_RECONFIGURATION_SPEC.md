# Anchor Zero — Major Reconfiguration Boss Specification

**Region:** Periapsis Core outer layer  
**Encounter ID:** BOSS_PC_ANCHOR_ZERO  
**Type:** Mandatory infrastructure-scale boss/reconfiguration system  
**Retry:** PC13 Relay  
**Primary tests:** gravity orientation, subsystem responsibility, world-state variants, full movement fluency, 1–4 player scaling

## Fantasy

Anchor Zero is the original master Mass Anchor.

It behaves like a mechanical organism because its articulated rings continuously correct orbital load, isolate damaged subsystems and reorient the surrounding structure.

It is infrastructure, not a sentient monster.

The player's goal is to bring it into **Neutral Zero** so final configuration becomes possible.

## Design rule

Anchor Zero must not become:

> “press every ability once.”

Each phase emphasizes a small subset of systems, selected partly by current world state.

## Arena

A multi-ring Periapsis chamber with:

- central Anchor Zero core;
- three rotating orientation rings;
- four subsystem docks;
- Phase-compatible signal rails;
- Flux-inert emergency braces;
- movable counterweights;
- recovery anchors.

Gravity/orientation changes are authored ring states.

No free arbitrary global gravity simulation.

# Phase 1 — Orientation Error

**Target:** 90–150 seconds.

Anchor Zero rotates the arena through three authored orientations.

Player tasks:

- move between ring surfaces;
- Latch/Orbit moving anchors;
- Vector Shift between orientations;
- stabilize two orientation clamps.

World-state influence:

- Atmospheric Support may create helpful/hazardous current.
- Structural Access changes available heavy anchors.

### Solo

Sequential clamps; Echo holds one during overlap.

### 2P

Paired clamps.

### 3P

Pair + moving-counterweight role.

### 4P

Two pairs.

## Attacks/hazards

- Ring Sweep;
- Counterweight Pass;
- Anchor Rejection;
- Alignment Pulse.

# Phase 2 — Subsystem Conflict

**Target:** 120–210 seconds.

Anchor Zero detects incompatible regional states and isolates subsystems.

The game selects **2 of 4 authored subsystem conflict modules** from the current world snapshot.

### Power Conflict

Overloaded active machinery versus low-power dead routes.

Uses Flux/Inversion.

### Thermal Conflict

Heat/coolant/pressure imbalance.

Uses environmental movement and support routing.

### Signal Conflict

Material/Resonant interference.

Uses Phase/Link.

### Structural Conflict

Moving braces and heavy mass.

Uses Attract/Repel/Flux/Link.

Selection is deterministic and previewed in PC13 diagnostics.

## Goal

Resolve each active subsystem enough to lower Zero's Rigidity state.

# Phase 3 — Master Relationship

**Target:** 90–150 seconds.

Anchor Zero tries to reassert its historical master relationship over every regional Anchor line.

The player does **not** choose an ending here.

Instead, the party severs exclusive control and opens three control paradigms:

- Central;
- Distributed;
- Resonant Interface.

These become configurable later in PC16.

## Mechanics

- Invert master tether;
- Phase into control rail;
- Flux inert release nodes;
- Link/Echo hold opposing relationship;
- direct Attract/Repel to move counterweight.

## Four-player structure

Four players can occupy:

- Central bus;
- Regional bus;
- Signal bus;
- stabilization/rescue.

Roles rotate after each bus action.

## Astral Shepherd reward

If Alignment Reserve is present:

- one dangerous orientation sequence is shortened;
- an emergency anchor appears;
- Neutral Zero stability window is wider.

It does not skip the boss.

# Neutralization finish

Once the master relationship is released:

- Anchor Zero enters Neutral Zero;
- all branches remain technically inspectable;
- final configuration is not yet committed.

This separation is essential for player agency and save/retry.

# Scaling

| Players | Structure |
|---:|---|
| 1 | sequential subsystems + Echo |
| 2 | paired clamps/subsystems |
| 3 | pair + flex/counterweight |
| 4 | two pairs / four buses |

Integrity scaling remains modest; objective concurrency does most scaling.

# Failure/retry

- retry from PC13;
- no mandatory dialogue replay;
- subsystem selection remains stable for the saved world state;
- wipe restores deterministic ring orientation.

# Accessibility

Per-player options may adjust:

- orientation transition speed;
- current/hazard intensity;
- target acquisition;
- Phase contrast;
- telegraph duration;
- incoming damage;
- Echo timing windows.

No accessibility option changes ending availability.

# Network

Server owns:

- ring orientation state;
- subsystem module selection;
- clamp state;
- counterweight state;
- Phase topology;
- master-relationship state;
- boss phase.

Clients interpolate ring/platform motion and presentation.

No replicated arbitrary gravity-field simulation.

# Narrative meaning

Anchor Zero demonstrates that the pre-fracture Meridian was never “neutral.”

Its architecture assumes centralized control and historical operating priorities.

Neutralizing it creates choice; it does not reveal a correct configuration.

# Acceptance criteria

- feels like reconfiguring infrastructure;
- world state materially changes active modules;
- no phase requires every ability simultaneously;
- 1–4 player responsibilities remain active;
- deterministic resets;
- Neutral Zero cleanly separates boss victory from ending choice.
