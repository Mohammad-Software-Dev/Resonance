# Resonance Documentation

The original numbered filenames from Google Drive are preserved, but the repository groups them by implementation use.

## Structure

- `design/foundation/` — vision, game loop, movement, Resonance, combat, co-op, progression, world, narrative, enemies, levels, multiplayer, UI, art, roadmap, business, legal, telemetry and Version 1 scope.
- `design/opening-and-canon/` — playable cast, first hour, canonical ability/world/enemy/boss graphs, four-player specs and vertical-slice production documents.
- `technology/architecture/` — browser-first architecture, networking/deployment, shared simulation/physics, persistence, content tooling, performance/CI and risk.
- `technology/m0/` — implementation-ready M0 repository, tick/state, Babylon, Rapier/controller, TargetID/Attract/Repel, tests and backlog specs.
- `regions/` — detailed production specifications grouped by region.
- `production-and-canon/` — canonical campaign flow, supersession register, scope matrix, milestones, engineering gates, dependencies, campaign-state schema and terminology.
- `archive/superseded-duplicates/` — copied Drive duplicates retained only for traceability.

See [MIGRATION_MANIFEST.md](MIGRATION_MANIFEST.md) for the Drive-to-GitHub mapping.
