## Launch-critical pillars

Protect before optional content:

1. movement quality;
2. browser rendering stability;
3. Attract/Repel;
4. dedicated-server prediction;
5. Link;
6. Echo;
7. 1–4 online;
8. streamable content pipeline;
9. save/reconnect correctness;
10. core ability progression;
11. critical regions/bosses;
12. world transformation;
13. accessibility;
14. finale distinction.

## First cut order

Cut optional rooms, mini-bosses, secondary quests, Module variants, cosmetic variants, superbosses and extra afterstate routes before weakening the launch-critical pillars.

Bounded Accord is only a contingency deferral if final-branch QA complexity threatens core launch quality.

## Release-quality rule

A smaller 60-fps, reliable browser game is preferable to a larger game with loading stalls, network correction or renderer instability.
