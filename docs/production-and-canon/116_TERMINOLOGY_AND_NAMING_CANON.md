# Terminology and Naming Canon

**Status:** Iteration 3J  
**Purpose:** Give design, engineering, UI, narrative, art and QA one vocabulary.

# World

## The Meridian

The orbital habitat/world.

Use:

- “the Meridian” in prose;
- Meridian systems/infrastructure.

Avoid treating Meridian as the name of a planet.

## Gas giant

The planet the Meridian orbits.

Its final proper name is not required by current design unless narrative chooses to name it later.

# Characters

## Wayfarer

One of the four named playable characters:

- Mara Venn;
- Ily Sare;
- Jun Vale;
- Oren Kade.

“Wayfarer” is a role/identity, not a generic player class selection.

# Core interaction terminology

## Resonance

Umbrella term for the game's force/field interaction system and related world phenomenon.

Do not use Resonance as a synonym for every supernatural/technical event without context.

## Resonant target / anchor

A valid target for relevant Resonance interaction.

## Attract / Repel

Fundamental directional-force verbs.

## Link

Validated relationship between player and teammate/object/system.

Use capitalized **Link** for the player mechanic.

## Echo

Deterministic solo-recording/proxy mechanic.

Echo is not:

- AI companion;
- clone pet;
- autonomous party member.

## Latch

Tap-to-commit movement toward valid anchor.

## Orbit

Maintain relationship radius to create angular movement.

## Vector Shift

Airborne route reassignment.

Use full name in first UI/tutorial reference.

## Flux

Temporary change in **target eligibility**.

Canonical design sentence:

> Flux changes what can respond.

## Phase

Change in **player field-state occupancy**.

Canonical states:

- Material;
- Resonant.

Avoid calling this a shadow world, spirit world, alternate dimension or duplicate world.

## Invert

Reverse a selected **relationship**.

Canonical design sentence:

> Invert reverses the relationship.

Avoid:

- time reversal;
- global gravity flip;
- universal polarity swap.

# Player-state resources

## Health

Stable health.

## Fracture / Fracture Health

Recoverable recent damage layer defined by combat specs.

## Stability

Armor/posture/force-resistance concept.

## Heat

Resonance resource/pressure used by selected abilities.

Exact balance remains tunable.

# Build terminology

## Core

Major loadout family.

Canonical families:

- Vector;
- Breaker;
- Weaver;
- Conduit;
- Mender;
- Ghost.

## Module

Smaller loadout modifier/technique.

Do not call Modules “charms” in design/UI.

## Bandwidth

Capacity for equipped Module/loadout budget where defined.

# World systems

## Mass Anchor

Large infrastructure that stabilizes major Meridian relationships/orbital/region state.

## Anchor Zero

Original master Mass Anchor in Periapsis.

Not a deity or creature.

## Relay

Save/fast-travel/loadout/session-safe infrastructure.

Use “Relay” consistently.

## Transit Spine

Core connective infrastructure.

## Broken Transit Crown

Late transformed/occupied upper Transit region.

“Crown” is acceptable shorthand after first reference.

## Periapsis Core

Final region.

Use “Periapsis” as shorthand after first reference.

# Tessel

Canonical:

distributed field intelligence/life phenomenon.

Known:

- remembers;
- adapts;
- coordinates;
- communicates;
- exhibits self-preservation.

Intentionally unresolved:

- one vs many;
- origin;
- memory boundaries;
- long-term motives.

Avoid definitive prose calling Tessel:

- “the AI”;
- “the alien”;
- “the ghost”;
- “the god.”

# Custodians

## Custodian Assembly

Technical/governance institution focused on validated infrastructure and emergency stability.

Not a generic empire/evil army.

## Meridian Custodian

Mandatory Crown boss role/operator.

## Anchor Knight

Custodian elite field-operator rig.

Name is a field nickname; visual design must remain technical, not medieval.

# Deprecated terms

Do not use as current canon:

- “The Pale Engine” as final boss name;
- old provisional Custodian Runner / Brace Guard / Field Auditor / Relay Seizer / Protocol Drone family;
- “shadow world” for Phase;
- “Hollow Knight-like” in internal design descriptions;
- “co-work mode” as product terminology;
- couch/split-screen Version 1 language;
- “true ending” or “golden ending.”

# Document language rule

When describing a mechanic:

1. state what gameplay category it changes;
2. state what it does not change when confusion is likely;
3. use exact capitalized term consistently.

This is especially important for Flux, Phase and Invert.
