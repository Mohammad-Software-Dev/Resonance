# Canon, Scope and Version 1 Promise

## Product identity

Resonance is a browser-first 2.5D precision action-exploration Metroidvania with first-class solo and 1–4 player online co-op.

The same TypeScript gameplay code powers:

- desktop browsers;
- installable PWA;
- Steam/Electron desktop client.

## Version 1 product commitments

### 1. Browser first

Primary launch runtime:

- modern desktop web browser.

Steam:

- packaged Electron build using the same game client and servers.

PC remains the hardware/platform focus.

Console ports are future evaluation, not Version 1 commitment.

### 2. 2.5D presentation

- 3D environments;
- 3D lighting/materials;
- side-view precision gameplay;
- strong silhouettes;
- authored depth.

### 3. Solo + 1–4 online

- one human per client;
- no couch/split-screen;
- no multiplayer retrofit later.

Solo is intentionally complete.

### 4. Echo solo parity

Required simultaneous co-op ideas receive intentional Echo equivalents.

Solo never requires a human partner.

### 5. Named ensemble cast

Playable roster:

- Mara Venn;
- Ily Sare;
- Jun Vale;
- Oren Kade.

Shared baseline moveset, distinct identity/personality.

### 6. Challenging baseline + granular accessibility

Difficulty comes from:

- movement mastery;
- boss learning;
- readable decision pressure;
- build understanding;
- cooperation.

Accessibility modifies barriers without changing ending access.

### 7. Moderate story density

- central mystery;
- regional stories;
- recurring NPCs;
- party relationships;
- meaningful world choices;
- multiple final configurations;
- environmental lore.

## Time targets

Planning targets:

- main campaign: approximately 18–22 hours;
- completionist: approximately 30–40 hours.

These are tuning/scope targets, not reasons to add filler.

## Content targets

Current launch planning:

- 4 named Wayfarers;
- 1–4 players;
- 9 major-region sequence including opening/connective/finale structure;
- 9 mandatory major-boss slots + opening mini-Guardian;
- approximately 40–44 strong enemy archetypes after consolidation;
- 6 Core families;
- four final configuration designs if production risk permits.

Detailed room counts live in production region files.

## Browser performance promise

Version 1 should target:

- 60 fps baseline on defined Tier M desktop hardware;
- WebGPU high-quality path;
- WebGL2 compatibility fallback;
- gamepad + keyboard/mouse;
- streamed content rather than full-game initial download.

Mobile touch is not Version 1 target.

## Online promise

- dedicated authoritative servers;
- invite/private party;
- reconnect;
- browser refresh recovery;
- region selection;
- 150 ms RTT design target.

Public matchmaking optional.

## Scope-reduction order

Cut first:

1. optional rooms;
2. cosmetic quantity;
3. optional Chambers;
4. secondary quests;
5. optional bosses;
6. extra Module variants;
7. optional afterstate routes;
8. Bounded Accord only under severe final-branch QA pressure.

Protect:

- movement quality;
- Attract/Repel;
- Link;
- Echo;
- 1–4 online architecture;
- browser performance;
- critical region identity;
- critical bosses;
- world transformation;
- save/network correctness;
- accessibility;
- finale distinction.

## Not required for Version 1

- couch/split-screen;
- mobile touch version;
- public matchmaking;
- New Game+;
- fully explorable post-ending worlds;
- shared group-owned campaign;
- console release.

## Team assumption

Full production likely requires approximately 10–14 core staff plus contractors/QA if the current content scope is retained.

A smaller team implies fewer optional rooms/enemies/quests or a longer schedule.

## Completeness definition

Version 1 is complete when:

- full story works solo;
- full story works with 1–3 friends;
- every foundational ability works;
- all critical regions and bosses work;
- regional choices propagate correctly;
- at least one standard final configuration is reachable without guide dependence;
- browser performance/network/save behavior meets acceptance gates;
- Steam/Electron build uses the same gameplay code rather than a separate port.
